# B. Now (PrompTugal.news · Data)

Big live numbers first: active warnings by level, stations reporting, airline flights near Faro now, and municipalities above the lowest fire risk class today. Each number carries its source link and the time it was read. All sources follow in a list with status and headline count.

Data: read at run time from each source's `latest.json` (counts.by_level, counts.reporting, counts.airline, counts.today_by_level). A source that cannot be read shows "not read yet".

Best for the curious reader. Weak at breadth: four numbers lead and the terms are not on view.

HTML version: [index.html](index.html). All three: [choose](../index.md).
