# C. For builders (PrompTugal.news · Data)

The endpoint first: the stable address of the catalogue and of each source's latest.json, a copyable curl line for each, links to the OpenAPI description and Swagger, then the status and time read.

Data: addresses are fixed text; status is read at run time from each source's `latest.json`. If a source cannot be read it shows "not read yet". The Swagger address (`api/v1/docs/`) is a guess until the API build says where it lives.

Best for developers and agents. Weak for readers who want values rather than addresses.

HTML version: [index.html](index.html). All three: [choose](../index.md).
